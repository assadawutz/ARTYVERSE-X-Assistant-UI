# Switches

- **Provenance:** Existing workspace app, `artifacts/artyverse-assistant/src/App.tsx` and `src/index.css`.
- **License:** Workspace source; no third-party switch implementation copied.
- **Source patterns:** `.switch`, `.switch.on`, and `role="switch"` preference buttons.
- **Usage evidence:** Auto-scroll and sentence-highlight settings use compact binary toggles with a white thumb and pink enabled track.
- **Public family:** Controlled switch with `checked`, `onCheckedChange`, disabled, keyboard, and ARIA states.
- **Dependencies:** React. Preserve native button and switch semantics from the source.
