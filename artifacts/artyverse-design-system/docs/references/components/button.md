# Buttons

- **Provenance:** Existing workspace app, `artifacts/artyverse-assistant/src/App.tsx` and `src/index.css`.
- **License:** Workspace source; no third-party button implementation copied.
- **Source patterns:** `.header-button`, `.pause-button`, `.outline-tool`, `.read-button`, `.done-button`, `.send-button`, and `.queue-strip button`.
- **Usage evidence:** Header settings/menu actions, listening pause/resume, speaker controls, settings completion, and composer send.
- **Public family:** Native button semantics with primary, lime, outline, ghost, and icon treatments; supports disabled, pressed, focus-visible, and loading states.
- **Dependencies:** React. The source uses inline native buttons, not a headless behavior library.
