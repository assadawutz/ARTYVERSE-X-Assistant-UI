# Cards and surfaces

- **Provenance:** Existing workspace app, `artifacts/artyverse-assistant/src/App.tsx` and `src/index.css`.
- **License:** Workspace source; no third-party card implementation copied.
- **Source patterns:** `.script-card`, `.queue-item`, `.settings-panel`, and `.topbar`.
- **Usage evidence:** The speaker script is the primary reading surface; queue entries and settings use related white surfaces with cool borders and restrained elevation.
- **Public family:** Card container, header, title, description, content, and footer primitives. Consumers compose responsive panels from these pieces.
- **Dependencies:** React. The source uses semantic `article`, `aside`, `div`, and CSS rather than a card library.
